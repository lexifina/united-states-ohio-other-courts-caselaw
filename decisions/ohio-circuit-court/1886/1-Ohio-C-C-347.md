# Pope v. Pollock

## Majority (Cox, J.)

Cox, J.
We think the statute is imperative. Although the language is, 11 may set aside” yet that it should be construed as if written “ shall set aside.” The affidavit in this case, showing in our opinion a good and sufficient reason for the absence of the defendant at the trial, the magistrate should have set the judgment aside. Judgment reversed.
W. H. Pope, for plaintiff in error.
Reuben Tyler, for defendant in error.
